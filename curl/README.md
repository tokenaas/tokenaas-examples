# cURL examples

Raw HTTP against `https://tokenaas.ai/v1`.

## Environment

```bash
export TOKENAAS_API_KEY="sk-..."
export TOKENAAS_BASE_URL="https://tokenaas.ai/v1"
```

## List models

```bash
./list-models.sh
```

## Chat completion

```bash
./chat.sh
```

## Streaming chat

```bash
./chat-stream.sh
```

## Image generation

```bash
./image.sh
```
